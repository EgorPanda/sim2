# Sim2 — Руководство пользователя (M1.6 «Морфогенная регуляция и клеточная память»)

Русскоязычный интерфейс симулятора многоклеточного развития. Ядро симуляции
находится в `src/SimulationCore` и не зависит от Godot; интерфейс только рисует
данные ядра и позволяет редактировать черновик конфигурации.

---

## 1. Быстрый старт

```bat
dotnet build Sim2.slnx
godot --path E:\sim23
```

Для запуска готового эксперимента:

```bat
godot --path E:\sim23 -- --experiment res://config/experiments/multicellular.json
```

Проверка сборки (без окна и в окне):

```bat
dotnet build Sim2.slnx
dotnet test src\SimulationCore.Tests\SimulationCore.Tests.csproj
godot --path E:\sim23 --headless -- --selftest
godot --path E:\sim23 --headless -- --uitest
godot --path E:\sim23 -- --uitest
```

`--uitest` сам открывает лабораторию (кнопка, `L`, `F1`), проверяет переходы
«Справочник»/«Геном»/«Морфогены», применение черновика, все 7 слоёв и
сохранение профиля; выходит с кодом 0 при успехе.

## 2. Управление миром

| Действие | Управление |
|---|---|
| Выбрать клетку | ЛКМ |
| Панорама | ПКМ/средняя кнопка + перетаскивание, или WASD |
| Масштаб | колесо мыши |
| Пауза / продолжение | Пробел (или кнопка «Поставить на паузу») |
| Шаг на один такт | `.` / → (кнопка «Шаг»), только на паузе |
| Сброс эксперимента | `R` (кнопка «Сброс») |
| Удалить выбранную клетку | Del / Backspace |
| Режим удаления | `E` (ЛКМ убирает клетку) |
| Лаборатория | `L` (кнопка «Лаборатория…») |
| Справочник | `F1` (кнопка «Справочник») |
| Закрыть лабораторию | `L` или `Esc` |

Левая панель: транспорт, скорость, переключатель слоя, режим удаления.
Правая панель: статистика, численность фенотипов и инспектор выбранной клетки.
Внизу слева: панель фильтров морфогенов (для слоя «Смесь морфогенов»).
Внизу по центру: легенда слоя концентрации и сообщения системы.

## 3. Слои визуализации («Мир»)

Слой — способ посмотреть на то же самое состояние мира. Слои не меняют симуляцию.

- **Типы клеток** — базовый вид: цвет по фенотипу, умирающие клетки гаснут,
  готовые к делению подсвечиваются жёлтым.
- **Концентрация морфогена** — тепловая карта выбранного *внешнего* поля с легендой.
  Опции: нормализация к максимуму / абсолютная шкала (задайте мин/макс),
  подкраска клеток поверх поля, показ клеток.
- **Смесь морфогенов** — наложение сразу нескольких внешних полей. В левой нижней
  панели «Фильтры морфогенов» включайте/выключайте нужные сигналы; цвета
  смешиваются в реальном времени. Удобно, когда клетки выделяют несколько
  веществ одновременно.
- **Градиент** — стрелки направления и величины градиента выбранного *внешнего* морфогена;
  настройте шаг сетки, длину и прозрачность стрелок.
- **Внутриклеточная концентрация** — цвет клетки по локальной концентрации
  выбранного *внутреннего* морфогена. Для внутренних сигналов нет пространственного
  поля и градиента: каждая клетка хранит своё значение.
- **Активность гена** — если условия гена выполнены в клетке: зелёная; подавлен
  ген — красная; выключен (условия не выполнены) — серая.
- **Подавленные гены** — красным отмечены только клетки, где ген был навсегда
  подавлен эффектами «Подавление гена».
- **Соседи** — плотность клеточного окружения.

Тот же переключатель есть в левой панели и во вкладке «Мир» лаборатории.

## 4. Лаборатория

«Лаборатория» (`L`) открывается в **отдельном окне**, чтобы не закрывать обзор
симуляции. Она работает с **черновиком** — безопасной копией текущей
конфигурации. Пока не нажато **«Применить»**, симуляция не меняется. Закрывается
окно клавишей `L` или `Esc`, кнопкой «Закрыть (Esc)» в правом верхнем углу или
стандартной кнопкой закрытия окна.

Кнопки наверху панели:

- **Применить** — проверить черновик и, если ошибок нет, пересобрать мир.
- **Проверить** — показать ошибки и предупреждения без применения.
- **Восстановить** — отбросить правки и вернуть редактор к состоянию симуляции.
- **Сохранить** — записать черновик в профиль эксперимента (JSON). Если
  эксперимент был загружен, перезаписывается его папка; иначе откроется
  «Сохранить как…».
- **Загрузить…** — открыть другой профиль эксперимента.

Внизу панели выводятся результаты проверки: `【ошибка】` указывает на нерабочую
конфигурацию (применить нельзя), `【предупреждение】` — на редакцийные
недочёты. У каждой записи показаны раздел и при необходимости подсказка.

### 4.1 «Геном»

Слева — список геномов и генов, кнопки `+ ген` / `копия` / `удалить`.
Карточка гена справа:

- **Ид** — стабильный технический идентификатор (менять осторожно: на него
  ссылаются подавления). Используется для состояния гена в клетках.
- **Имя, Название, Роль, Описание** — имя используется в интерфейсе;
  «Название» это русское отображаемое имя (если пусто — имя из идентификатора).
- **Задержка, с** — сколько секунд гены ждут перед активацией с момента начала
  выполнения условий.
- **Обязательный сигнал активации** — отдельный морфогенный порог, который ген
  проверяет *независимо* от остальных условий. Если он включён, ген активируется
  только при достижении порога выбранным морфогеном (внешний — по полю в точке
  клетки, внутренний — по локальной концентрации внутри клетки). Новые гены
  создаются с включённым триггером; старые гены без этого поля работают по
  историческим правилам.
- **Условия** — блок логики.

#### Условия: группы и операторы

Гены следуют модели: **внутри группы — И, между группами — ИЛИ**.

- «Группа 1» с условиями [радиус ≥ 16] И [соседи ≥ 2] активна, когда клетка
  доросла **и** окружена.
- Две группы [таймер «развитие» идёт] ИЛИ [тип клетки = рабочий] дают ген,
  который включается по любому из двух поводов.
- Отдельное условие может быть **«НЕ»** (инверсия): «НЕ тип клетки = рабочий».
- Если условий нет — ген активен **всегда**.

Пороговые условия хранятся как интервал `[min, max]` и в интерфейсе отображаются
операторами:

| Как задать | Что сохраняется | Отображается |
|---|---|---|
| отключить «нижний предел» | `min = −∞` | нет нижней границы |
| отключить «верхний предел» | `max = +∞` | нет верхней границы |
| оба предела равны | `min = max` | `= значение` |
| разные пределы | `min < max` | `значение … значение` |
| только нижний | `min` конечный | `≥ значение` |
| только верхний | `max` конечный | `≤ значение` |

Типы условий: **Концентрация морфогена**, **Свойство клетки** (радиус, возраст,
соседи), **Тип клетки**, **Состояние клетки**, **Состояние таймера**.

#### Эффекты

- **Выделение морфогена** — клетка добавляет морфоген (ед./с). Для *внешнего*
  морфогена — в пространственное поле, для *внутреннего* — в локальное хранилище
  самой клетки. Пока ген активен, выделение повторяется каждый шаг; режим
  `once` ограничивает эффект одним импульсом при активации.
- **Рост** — увеличение радиуса до максимума типа.
- **Деление** — накопление готовности к делению (скорость). Дополнительный
  параметр **фенотип дочерней клетки**: если задан, дочерняя клетка рождается
  сразу этим типом (родитель сохраняет свой); если не задан (по умолчанию) —
  потомок наследует фенотип родителя, как раньше.
- **Смена типа клетки** — переключение фенотипа.
- **Запуск таймера** — именованный таймер на заданную длительность. Условие
  «Состояние таймера» может просто ждать, пока таймер идёт, либо задавать
  **время от запуска** («не раньше» / «не позже», сек): тогда ген срабатывает,
  когда с момента запуска пройдёт указанное время (и остаётся активным после
  истечения таймера).
- **Апоптоз** — вероятность гибели в секунду; `0` = гибель сразу при активации.
  Встроенная смерть от старости или голода отсутствует: клетки умирают только
  через этот эффект (или вручную в «Режиме удаления»), так что гибель всегда
  задаётся пользователем на генном уровне.
- **Подавление гена** — навсегда отключает другой ген в этой клетке.
- **Блокировка деления** — пока ген активен, клетка не делится.
- **Движение по градиенту** — клетка смещается вдоль градиента выбранного
  *внешнего* морфогена. Режим **отталкивания** инвертирует направление. Скорость
  задаётся в единицах мира в секунду; условия гена решают, когда клетка движется
  (например, при наличии одного морфогена — двигаться к другому).

### 4.2 «Морфогены»

Список с поиском; у каждой записи — технический `id`, название (русское),
техническое имя, описание, **тип** (External — внешний, диффундирует в среде;
Internal — внутренний, хранится в каждой клетке отдельно), **диффузия**
(только для внешнего), **распад** (убыль), начальная концентрация
(для внутреннего в основателях), **цвет** на тепловой карте. «Добавить» создаёт
новый морфоген с уникальным id, «Копировать» — точную копию с новым уникальным id.
«Удалить» проверяет зависимости (эффекты выделения/движения, условия
концентрации, обязательные триггеры генов, «морфоген направления деления»):
при их наличии показывается диалог со списком ссылок — подтверждение чисто
удаляет морфоген и все ссылки на него (в том числе пустые группы условий,
незаданные обязательные триггеры и выбор морфогена направления), отмена
ничего не меняет. Пустой список морфогенов — допустимое состояние, интерфейс
не ломается.

### 4.3 «Типы клеток»

Биологические параметры фенотипа: радиусы (базовый/максимальный), цвет и
**ссылка на геном**, который этот тип экспрессирует. Жизнь и деление полностью
управляются генами: клетка не нуждается в пище и энергия не используется.
Удаление защищено проверкой ссылок.

### 4.4 «Настройки эксперимента»

Размеры мира, разрешение морфогенного поля, фиксированный шаг симуляции,
скорость по умолчанию, число клеток-основателей, сид генератора случайных
чисел, тип основателя и морфоген, направляющий деление. Также здесь задаются
**начальные сигналы**: локальные внешние источники (координаты, радиус,
концентрация, профиль) и начальные внутренние концентрации для клеток-основателей.
Без начального сигнала ген с обязательным триггером может остаться неактивным.
Изменение размеров или разрешения требует перезапуска эксперимента.

## 5. Справочник

Встроенный браузер (вкладка «Справочник» или `F1`). Поиск на русском и на
технических ключах (например, `diffusion`, «апоптоз», «градиент»). Из контекста
справку открывают «?» рядом с разделами редакторов, а переходы — из инспектора
клетки (клик по активному гену открывает редактор этого гена).

## 6. Рабочие сценарии

**Дифференцировка при делении** — прямое продолжение мастер-основателя: в общем
геноме два гена деления у стволовой клетки, различающиеся порогом концентрации
сигнала и задающие разный фенотип дочерней клетки (`childTypeId`), плюс
«Блокировка деления» у рабочих и покровных клеток. Дочери рождаются сразу
«рабочими»/«покровными», и такие клетки больше не делятся — колония не может
переполниться. Готовый пример — встроенный профиль `config/experiments/differentiation.json`
(файл + папка `differentiation/` с пятью JSON): откройте его через «Загрузить…» на
вкладке «Настройки эксперимента». Правки: добавьте «Фенотип дочерней клетки» в
эффект «Деление» и нажмите «Применить».

**Французский флаг.** Три типа клеток — стебель, рабочий, оболочка. Добавьте
три гена: каждый активен, когда концентрация сигнала в подходящем диапазоне
(низкая / средняя / высокая), и эффектом «Смена типа клетки» приводит клетку к
своему фенотипу. Задайте источники сигнала эффектами «Выделение морфогена» у
стеблевых клеток — через пару минут рост образует полосы.

**Апоптоз по таймеру.** Один ген запускает таймер «срок» на 30 с. Второй ген
с условием [таймер «срок», время от запуска ≥ 30 с] → апоптоз 0.05/с. Вариант
без времени: условие [НЕ таймер «срок» идёт] тоже сработает после истечения.

>**Клеточная память.** Встроенный профиль `config/experiments/cell_memory.json`
иллюстрирует внутренний морфоген: внешний сигнал A запускает производство
внутреннего сигнала B, после исчезновения A концентрация B сохраняется и
продолжает активировать ген `actFromB`, переключая клетку в фенотип «память».
Клетки, не попавшие в зону A, остаются стволовыми. Попробуйте замедлить распад
B (поле «Распад, 1/с» в редакторе морфогенов) — клетки будут помнить сигнал
дольше.

**Сохранение как эксперимента.** Внесите правки, нажмите «Сохранить» — будет
создан профиль (файл `имя.json` + папка `имя/` с пятью JSON конфигов). Запуск:
`godot --path E:\sim23 -- --experiment res://config/experiments/имя.json` или
кнопка «Загрузить…» в лаборатории.

## 7. Частые вопросы

- **Почему ген молчит?** Проверьте «Проверить»: возможно, не выбран обязательный
  морфогенный триггер, или условие ссылается на неизвестный регулятор, или
  интервал пуст, или у группы неподходящий оператор. Гены с обязательным
  триггером требуют наличия выбранного морфогена в конфигурации.
- **Почему клетка не делится?** Нужен активный ген с эффектом «Деление»,
  свободное место и отсутствие «Блокировки деления». Клетка, которая уже
  «дифференцирована», часто имеет активную «Блокировку деления» — так рабочие и
  покровные фенотипы не делятся по дизайну.
- **Куда пропал морфоген?** При удалении вместе с ним очищаются все ссылки
  (эффекты, условия, «морфоген направления деления», пустые группы условий) —
  для ссылок показывается подтверждающий диалог со списком.
- **Я изменил геном, но мир не изменился.** Правки живут в черновике — нажмите
  «Применить» (и при необходимости сбросьте эксперимент).
- **Can изменения потеряться?** До нажатия «Применить» всё в черновике;
  «Восстановить» возвращает к последнему применённому состоянию.

## 8. Глоссарий

| Техническое имя | Русский эквивалент |
|---|---|
| `EmitMorphogen` | Выделение морфогена |
| `Grow` / `Divide` | Рост / Деление |
| `SetCellType` | Смена типа клетки |
| `StartTimer` | Запуск таймера |
| `Apoptosis` | Апоптоз (программируемая гибель) |
| `SilenceGene` | Подавление гена |
| `BlockDivision` | Блокировка деления |
| `Move` | Движение по градиенту морфогена |
| RegulatorGroups | Логические группы условий: И внутри, ИЛИ между группами |
| `min`/`max` | Нижний/верхний предел (интервал для оператора сравнения) |
| Morphogen type | External / Internal — внешний (поле) или внутренний (память) |
| Required trigger | Обязательный морфогенный порог для включения гена |
